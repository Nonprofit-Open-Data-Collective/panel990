# Compute a sample frame's view rules against a data frame

Compute a sample frame's view rules against a data frame

## Usage

``` r
views(df, sfw, verbose = TRUE)
```

## Arguments

- df:

  A data frame.

- sfw:

  A sample frame.

- verbose:

  Print each view.

## Value

Invisibly, a named list of view results (tables / tapply summaries).
